# Raspberry Pi 5 Supervisor Scripts

This folder contains the Python scripts that run on the Pi 5.

## Role
- Receives UART telemetry from the Arduino Mega
- Logs data to CSV files
- Drives HDMI dashboard display with live plots
- Provides supervisory oversight (watchdog, fault logging)
