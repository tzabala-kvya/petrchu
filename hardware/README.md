# Hardware Documentation

All physical/electrical design documents for PetrChu.

## Folders

### `schematics/`
Circuit diagrams showing electrical connections. Include both source files (if editable) and exported images (PNG/SVG) so anyone can view them without special software.

### `wiring/`
Wiring diagrams and pinout tables. These show the practical "what connects to what" — wire colors, connector labels, terminal assignments.

### `panel-layouts/`
Control panel and demonstration panel SVG layouts. These show physical placement of components on the panels.

### `bom/`
Bill of materials. CSV format preferred (GitHub renders CSV as a table). Include: part name, part number, supplier, quantity, unit cost, link.
